# Robot Adventure Township

## 🎮 Project Overview

Robot Adventure Township is a 3D-style adventure township game developed as a Diploma Mini Project.

The game provides an interactive environment where the player can explore the township, move around the game world, and interact with different game elements.

## 🚀 Features

- Player movement
- Adventure-based gameplay
- Township environment
- Interactive game elements
- Save game data
- Simple and user-friendly gameplay

## 🛠️ Technologies Used

- Python
- JSON
- Game development concepts

## 📁 Project Files

- `township_game.py` – Main game source code
- `township_save.json` – Stores game save data
- `README.md` – Project documentation

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python township_game.py
